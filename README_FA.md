# راهنمای جامع راه‌اندازی و انتشار آنلاین «شبکه همکلاسی‌ها»

این پروژه یک وب‌سایت کامل، مدرن و آماده انتشار برای شبکه‌سازی اعضای دوره تلگرام است. تمام بخش‌های سایت به زبان فارسی، با فونت زیبای **وزیرمتن** و با چیدمان راست‌به‌چپ (RTL) بومی‌سازی شده است.

---

## 🚀 روش آنلاین کردن سایت برای دسترسی عموم و دوستان (۱۰۰٪ رایگان)

برای اینکه دوستان و همکلاسی‌های شما بتوانند از هر دستگاهی (موبایل یا لپ‌تاپ) وارد سایت شوند، پروفایل خود را ثبت کنند و پروفایل بقیه را ببینند، به دو چیز ساده نیاز دارید که هر دو **کاملاً رایگان** و بدون نیاز به کارت بانکی یا هزینه‌اند:

1. **یک هاست رایگان برای نمایش وب‌سایت** (مثل Vercel یا Cloudflare Pages یا Netlify)
2. **یک پایگاه داده ابری رایگان** (Supabase) برای اینکه داده‌های همه اعضا در یک دیتابیس مشترک ذخیره شود.

---

### گام اول: ساخت دیتابیس آنلاین رایگان در Supabase (۳ دقیقه)

1. وارد سایت [supabase.com](https://supabase.com) شوید و روی **Start your project** کلیک کنید و با اکانت گوگل یا گیت‌هاب خود وارد شوید.
2. روی **New Project** کلیک کنید:
   - نام پروژه: مثلاً `class-network`
   - یک رمز عبور دلخواه برای دیتابیس تعیین کنید.
   - ریجن (Region): نزدیک‌ترین (مثل Frankfurt یا Singapore) را انتخاب کنید.
   - پلن: Free Tier (رایگان مادام‌العمر).
3. اجرای اسکریپت ساخت جدول‌ها:
   - از منوی سمت چپ پنل Supabase، وارد **SQL Editor** شوید.
   - فایل موجود در پروژه به آدرس `supabase/migrations/20261101000000_init_directory.sql` را باز کرده و تمام محتوای آن را در این صفحه Paste کنید.
   - دکمه سبز رنگ **Run** را بزنید تا جدول اعضا، قوانین امنیتی RLS و باکت آپلود عکس‌ها ساخته شود.
4. دریافت کلیدهای اتصال:
   - از منوی چپ به **Project Settings** (آیکون چرخ‌دنده) و سپس **API** بروید.
   - دو مقدار زیر را کپی کنید:
     - **Project URL** (آدرسی مثل `https://xxxxxxxx.supabase.co`)
     - **anon public key** (یک کلید طولانی)

---

### گام دوم: انتشار سایت روی ورسل (Vercel) یا کلودفلر (Cloudflare Pages)

#### 🌟 روش پیشنهادی اول: از طریق Vercel (آسان‌ترین روش)
1. ابتدا پروژه را روی اکانت گیت‌هاب (GitHub) خود Push کنید:
   ```bash
   git remote add origin https://github.com/نام_کاربری_شما/class-network.git
   git branch -M main
   git push -u origin main
   ```
2. وارد سایت [vercel.com](https://vercel.com) شوید و با گیت‌هاب لاگین کنید.
3. روی **Add New... → Project** کلیک کرده و مخزن `class-network` را انتخاب (Import) کنید.
4. در بخش **Environment Variables** دو متغیر کپی‌شده از Supabase را وارد کنید:
   - نام: `VITE_SUPABASE_URL` | مقدار: آدرس پروژه شما
   - نام: `VITE_SUPABASE_ANON_KEY` | مقدار: کلید anon
5. دکمه **Deploy** را بزنید! در عرض کمتر از ۱ دقیقه یک لینک عمومی اختصاصی (مثل `https://class-network.vercel.app`) به شما داده می‌شود که می‌توانید آن را در گروه تلگرام برای دوستانتان بفرستید.

---

### گام سوم: پاکسازی پروفایل‌های تستی و شروع رسمی

۱. با کلیک بر روی دکمه **مدیریت** در بالای سایت وارد پنل مدیریت شوید.
۲. با مشخصات مدیر لاگین کنید (ایمیل: `admin@classnetwork.local` | رمز: `AdminClass2026!`).
۳. وارد تب **تنظیمات و پاکسازی** شوید.
۴. دکمه **«حذف تمامی پروفایل‌های تستی جهت انتشار نهایی»** را بزنید تا ۶ پروفایل نمونه تستی حذف شوند و سایت کاملاً تمیز و آماده ثبت‌نام واقعی همکلاسی‌هایتان شود!
۵. لینک سایت را در گروه یا کانال تلگرام به اشتراک بگذارید. اعضا ثبت‌نام می‌کنند و درخواست‌هایشان در تب **«در انتظار بررسی»** پنل مدیریت شما ظاهر می‌شود که می‌توانید با یک کلیک آن‌ها را تایید و در سایت منتشر کنید.

## 💻 اجرای آزمایشی روی سیستم خودتان (Local)

اگر می‌خواهید قبل از آپلود سایت را روی سیستم خود ببینید و تست کنید:

```bash
# نصب پکیج‌ها (در صورت نیاز)
npm install

# اجرای سرور توسعه محلی
npm run dev
```

سپس مرورگر خود را باز کرده و آدرس `http://localhost:5173` را وارد کنید.
پروژه بدون نیاز به اینترنت و بدون نیاز به هیچ تنظیماتی بلافاصله با حافظه داخلی مرورگر و پروفایل‌های نمونه ایرانی کار می‌کند!
